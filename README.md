Landing page oficial de **Albas en el Aula**, una cuenta educativa de TikTok e Instagram creada por dos maestras opositoras especializadas en Educación Infantil.

La web sirve como punto de presentación y venta de materiales educativos: temario de oposiciones, recursos para el aula, fichas y guías de metodología.

---

## ✨ Funcionalidades

- **Navbar responsive** con menú hamburguesa para móvil
- **Animaciones de scroll** — las secciones aparecen y desaparecen al hacer scroll
- **Sección Hero** con llamada a la acción
- **Sección Quiénes somos** con tarjetas individuales para cada Alba
- **Sección Qué ofrecemos** con tarjetas de categorías
- **Catálogo de materiales** con:
  - Tarjetas con efecto flip (frontal con foto, trasera con descripción y compra)
  - Filtros por categoría (Oposiciones / Para el aula)
  - Subfiltros por temática (Desarrollo cognitivo / Lectoescritura / Lógico-matemáticos / Desarrollo simbólico / Expresión musical /  Juego simbólico)
- **Sección FAQ** con acordeón desplegable
- **Footer** con enlaces a redes sociales y formulario de suscripción
- **Popup de newsletter** con memoria (no vuelve a aparecer tras suscribirse)
- **Banner de novedad** con enlace a materiales y botón de cierre
- **Botón volver arriba** que aparece al hacer scroll
- **Indicador de sección activa** en el navbar
- **Meta tags** para previsualización en redes sociales y WhatsApp
- **Favicon** con el logo de la cuenta

## ⚙️ Cómo ejecutarlo en local

1. Clona el repositorio:
```bash
   git clone https://github.com/davidfg02/albas-en-el-aula.git
```
2. Abre la carpeta en VSCode
3. Instala la extensión **Live Server**
4. Haz clic derecho en `index.html` → **Open with Live Server**
